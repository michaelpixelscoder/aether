# Continuous 5×5 wooden-plank macro master

Use case: `stylized-concept`  
Asset type: square 5×5 voxel macro-panel base-color master, sliced deterministically into UV regions.

Edit the prior wooden-plank source. Preserve dark walnut, aged-brass nails,
orthographic framing, and game-texture quality. Make exactly five equal-height
horizontal planks. Each is one uninterrupted 1×5 board: grain, fibers, knots,
and wear flow continuously left-to-right through x=20%, 40%, 60%, and 80%.
Only x=0% and x=100% receive outer bevels; use restrained nails near those
outer edges. Horizontal seams occur only at y=20%, 40%, 60%, and 80%.

Avoid vertical seams, independently tiled panels, a sixth plank, perspective,
baked lighting, cast shadows, text, logos, or extra fasteners.
